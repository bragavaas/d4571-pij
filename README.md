# Intercâmbio de Jovens — Rotary Distrito 4571 (PIJ)

Protótipo do portal público do Programa de Intercâmbio de Jovens do Rotary —
Distrito 4571 (Rio de Janeiro e São Paulo).

- **`index.html`** — o site completo em um único arquivo autossuficiente
  (HTML/CSS/JS puro, sem dependências, estado apenas em memória).
- **`docs/`** — documentos oficiais recuperados do site anterior do programa
  (Edital 007 LTEP 2025/26, Edital 008 Jovem Destaque, errata, Regulamento
  P.I.I.J. assinado e fichas/termos em DOCX).
- **`PENDENCIAS.md`** — lista de pendências de conteúdo a preencher pela
  Comissão Distrital antes da publicação oficial. Tudo que ainda não foi
  confirmado aparece no site como placeholder `[[entre colchetes duplos]]` ou
  com o rótulo "exemplo ilustrativo".

## Como visualizar

Abra `index.html` no navegador, ou acesse a versão publicada no GitHub Pages.
No rodapé há um link "Demonstração de estados do ciclo" para visualizar o
portal com inscrições abertas, encerrando, encerradas ou ainda não abertas.

## Avisos importantes

- **Protótipo**: os formulários não enviam dados; validação e confirmações são
  simuladas no navegador. A inscrição formal em produção exigirá backend
  seguro e conformidade LGPD para dados de menores.
- **Logo**: o lockup em SVG é uma aproximação — antes da publicação oficial,
  substituir pelos arquivos oficiais do Rotary Brand Center fornecidos pela
  Comissão.
- Site mantido por voluntários do Distrito 4571 do Rotary International.
